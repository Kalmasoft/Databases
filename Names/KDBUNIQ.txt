#	ID: Reference ID
#	Name: name in Arabic script
#	Type: type of name
#		C: common, used for given and surnames
#		G: given name
#		S: surname, last name
#	Gender: name gender marker
#		F: female
#		M: male
#		U: unisex
#	Category: name categorization
#		I: indigenous name
#		L: loan name
#		Q: unique name
#	Origin: possible origin of the name
#		A: Arabic origin
#		N: non-Arabic origin
#	Country: two-letter country code.
#		NN: Non-native name or neutral name,
#		DZA: Algeria, BHR: Bahrain, EGY: Egypt, IRQ: Iraq, JOR: Jordan, IRN:  Iran,
#		SAU: Saudi Arabia, KWT: Kuwait, LBN: Lebanon, LBY: Libya, MRT: Mauritania, 
#		MAR: Morocco, OMN: Oman, PSE: Palestine, QAT: Qatar, SDN: Sudan, COM: Comoros

# =========================================

# 2- names of non-Arabic origin are those found in non-Arab communities or in the peripheries of the Arab world.
# 3- romanized version is available on request.
# 4- This database is continuously being updated.
# =========================================
